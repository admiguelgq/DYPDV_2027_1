Asegúrate de Configurar OpenGL https://www.geeksforgeeks.org/installation-guide/how-to-setup-opengl-with-visual-studio-2019-on-windows-10/
Tener :
- Librería OpenGL (OpenGL32.lib).
- Librería GLU (GLu32.lib).
- Librería GLUT / FreeGLUT (glut32.lib y glut32.dll).

Compilar Proyecto Pong

En Visual Studio:
  1. Abre el archivo de solución 'Pong.sln'.
  2. Selecciona la plataforma 'x86' en la barra superior.

Ejecutar
	Presiona el botón de iniciar

Controles
Jugador1 (Rectángulo izquierdo) arriba: w  abajo: s
Jugador2 (Rectángulo derecho) arriba: Flecha arriba  abajo: Flecha abajo
